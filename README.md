# Währungsrechner (Python) 

Einfacher Konsolenwährungsrechner mit 10 Währungen inkl. CFA-Franc (Kamerun).
A Python console app that converts between 10 currencies using fixed exchange rates — no API needed. I included the CFA Franc (XAF) used in Cameroon and Central Africa, alongside EUR, USD, GBP, JPY, and others. The conversion logic routes all calculations through EUR as a base currency. I focused on clean input validation, meaningful error messages, and a simple interactive loop. A good exercise in functions, dictionaries, and user input handling in Python.

## Technologien
- Python 3.10+
- Keine externen Bibliotheken nötig

## Unterstützte Währungen
EUR · USD · GBP · JPY · CAD · CHF · CNY · XAF (CFA) · NGN · ZAR

## Ausführen

```bash
python converter.py
```

## Funktionen
-  Umrechnung zwischen 10 Währungen
-  Eingabevalidierung mit Fehlerbehandlung
-  Interaktive Konsolenoberfläche
